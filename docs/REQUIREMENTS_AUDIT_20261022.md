## MD의 노드 흐름 대조

실제 메인 그래프는 `engine.py:329~350`에 있다.

```text
load: START → preflight → baseline → fault → recovery → integrity → END
integrity: START → preflight → integrity → END
그 뒤: 규칙 판정 → 선택적 로컬 AI 추천 → 실행 기록 완료
```

정합성 설정을 끄면 해당 노드는 검사 없이 통과한다. `analysis` 단계는 현재 그래프 실행 뒤의 Python 코드다. 노드 이름만 바꾸는 것으로 상세 MD의 기능을 충족하는 것은 아니다.

| 요구 역할 | 새 메인 대응 | 판정 |
|---|---|---|
| route / _after_route / Chat_answer | 없음 | 미충족 |
| plan: MCP Prompt + LLM Task 정의 | 사용자 설정·프리셋·파일 가져오기 | 해당 통합 미충족 |

| research: Tool + Runbook | 실제 HTTP 지표 수집은 있음. MCP Tool·Runbook 검색은 메인 미연결 | 부분 충족 |
