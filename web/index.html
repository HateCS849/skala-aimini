01 실험 설계

실행 중인 로컬 앱
TRAFFIC

급증·증가 패턴은 기준·회복 2명 → 부하 단계 최대 인원으로 실행합니다. 보호 기능 관찰에 설정 인원 중 1명을 사용합니다.

FAULT & OBSERVABILITY
외부 형식 오류 · DB 지연/잠금 · Redis 장애

추가 장애는 예제 또는 지원하는 제어 어댑터가 필요합니다. Redis 예제는 전용 로컬 Redis(16379)를 사용합니다.

정합성 · 실제 재시작 · 장시간 안정성

예제 프로세스 관리 상태 확인 중

장시간 시나리오는 기본 3분, 최대 1시간입니다. 관찰 시간이 부족하면 미확인으로 표시합니다. 임의의 앱 프로세스를 종료하지 않습니다.

사용자 행동 · 응답 조건 · 고급 설정

행동의 weight는 실행 비율입니다. 여러 steps를 넣으면 한 사용자가 순서대로 수행합니다. 본문에 {{vu}}, {{iteration}}, {{uuid}} 변수를 사용할 수 있습니다.

토큰·응답 본문·추출한 세션 값은 실험 기록에 저장하지 않습니다.

API 명세·운영 요구·장애 기록을 검색 근거로 사용합니다.

핵심 근거 모드는 실험 선택이 달라질 수 있습니다. 판정 수치와 원래 조건 검사 의무는 유지됩니다.

AI는 지정한 대상·API·최대 인원을 유지합니다. 원래 조건을 반드시 검사하고, 남은 예산에서 낮은 부하·장애 해제·반복 실험을 선택합니다. 추적은 로컬에 저장됩니다.

예제는 실제 HTTP·SQLite·전용 Redis를 사용하는 재현용 앱입니다. 실제 Hangari나 HikariCP의 측정 결과와는 구분합니다.
